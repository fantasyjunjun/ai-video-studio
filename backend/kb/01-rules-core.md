# 通用铁律（写每一条提示词都必须满足）

1. **每个分镜提示词独立完整**。禁止"同上""接上一镜"——模型不继承上下文。
2. **一致性锚点逐字复用**。人物锚点 + 产品锚点必须在每条提示词中原样出现，一字不改。
3. **中英双版本输出**。提示词正文用英文（视频模型英文更稳），必须附中文直译供人工核对。
4. **单一动作原则 + 节拍受镜长硬约束**。≤3s 镜只允许 1 个主动作，4–6s 允许 2 个。塞更多会被注意力平均成"缓慢微动"（观感="一张照片加滤镜"）。
5. **单镜内禁止物体出现、消失或状态改变**。不写开盖、拧盖、开盒、抽取、遮挡后现身。反向约束必须补 `no object appears, disappears or changes state`。
6. **因果自洽**：画面里每个**结果性元素**（雾/水珠/飞溅/烟/飘落物）必须有同镜可见的成因。三条解法：① 干脆不写该元素；② 单独做产品氛围镜（只有瓶身与雾）用剪辑制造因果；③ 按铁律 6/27 拍合法喷香水镜。
7. **反向约束内嵌正向提示词**（通道不接收 negative_prompt）。写成 `Do not … / Keep … intact` 祈使句附在末尾，每镜只列真正会踩的 3–5 条。
8. **手部是最高危元素**。"手靠近脸/胸前/持物的中间动作"大概率退化成爪状手指。优先设计无手部动作的镜；必须有手时只写**一个已完成的手势**或**一次明确按压**，不要让手"正在移动"。
9. **多产品同框必须逐件指派标签文字**。模型会把参考图的标签复制到所有瓶子上。写法：逐瓶显式写出该瓶标签文字 + 反向锁 `each bottle keeps its own label text; the two labels never share or swap words`。（该镜仍只能挂其中一张产品参考图，两张同挂会互相污染。）
10. **i2v 锚点段必须 ≤25 词**。参考图已承载外观，重写一遍会给模型两套冲突指令 → 脸被"平均化"、质感被拖平。只写"与参考图保持一致"+ 2–3 个最关键特征。
11. **每镜必须有唯一焦点（hero）**。显式声明唯一清晰焦点，其余元素显式降级 `everything else stays soft and subordinate`。
12. **香调事实分级，不许推断**。A=官方香调卡、B=权威媒体、C=无来源。**C 级一律不得写进文案，必须先问用户**。宁可抽象，不可错述。
13. **合规红线**：不用"最/第一/国家级"等绝对化用语，不宣称疗愈、催情、医疗功效，不出现未授权 logo 与明星面孔。
14. **"某元素第几秒出现"不能靠提示词解决**。模型对结果性元素有固有前摇且随时长等比增长。正确做法：接受前摇，后期裁剪，并按**实测真实起点**落音效。
15. **拼按时长必须按帧网格配平**。`-ss` 吸附 `1/fps`（24fps 用 `0.4166666667` 而非 `0.42`）；总时长按**帧数**相加（15s = 360 帧）；交付前 ffprobe 校验。

> **lint 满分 ≠ 出片没问题**：lint 只管提示词结构，管不了模型的时序行为与构图漂移。凡涉及"何时出现"，出片后必须逐帧复核。
