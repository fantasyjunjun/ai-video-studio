# 叙事弧与卖点可视化

用户定标：**"提示词不能是镜头分镜的堆砌，要模特把产品核心卖点和那种感觉在一条视频里有美感地展示出来。"** 反面教材就是"每镜技术合规（量化运镜 / NEG 锁死 / [AUDIO] 层齐全），但拼起来是静物幻灯片"。

## 参考片拆解（15s 香水片，逐段逆推）

| 时间 | 画面 | 为什么好 |
|---|---|---|
| 0-3s | 金瓶静物，**瓶周围摆着柠檬片 / 杏仁 / 咖啡豆 / 白玫瑰**（全是香调卡上的成分） | 钩子即卖点可视化：不说"citrus notes"，直接把柠檬摆进画面；静物自带信息量，不是空瓶 |
| 3-6s | 模特**闭眼侧脸，持瓶对颈侧喷**，暖金光 | 人在"用"产品，情绪可读（闭眼=沉浸）；道具仍在前景延续香调事实 |
| 6-9s | 黑瓶在浴室**蒸汽里**，随后模特黑裙立于浴缸旁举瓶 | 双产品=双情绪章节；蒸汽给"夜"章节做氛围可视化 |
| 9-12s | 模特**喷雾入竖直光束**，雾在光里可见；回眸 | 结果性元素绑了物理锚点（practical light + 逆光 rake），动作有目的 |
| 12-15s | 模特微笑收势 → **双瓶并排 packshot** | 情绪落到"自信满意"，收尾把系列事实（两只）一并交付 |

## 五条设计法则（写骨架时逐条过）

1. **先弧后镜**：先定情绪弧（好奇→亲近→使用→沉浸→自信），再让每镜落在一个点上；情绪只进不退。
2. **卖点必须看得见**：念白提柠檬，画面就得有柠檬——道具只从商品事实与商品图解读的可见元素里取，不许凭空造，也不许塞念白没提的道具抢戏。
3. **每镜有事件**：主动作写"谁对什么做了什么"；全片最多 1 镜纯静物（放钩子），人物情绪表达至少 2 镜。
4. **动作弧连续**：上一镜 exit_state = 下一镜 entry_state（同一姿态/位置），一条动作弧被切开，不是各自摆拍。
5. **结果性元素绑光锚点**：雾/蒸汽必须处在光束里才可见（practical light + 逆光 rake），这是"氛围感"唯一可靠的载体。

## 反面清单（实测踩过）

- 5 镜里 3 镜是"静物/静态微动"，模特只在背景虚化出现一次 → "一张照片加滤镜"。
- 念白说 notes of lemon，画面从头到尾没有柠檬 → 卖点悬空。
- 收尾产品镜首帧用了主播照（而非产品照）→ 模型凭空造场景，把场景参考图里的湿台面/蒸汽复刻进来（液体浇落穿帮）。首帧按画面主体选：产品主导镜给产品照，人物特写镜给主播照。
